# 120 mm 紧凑省料旋转盒 V2（一体底壳）

为约200g、重心靠近盘心的桌面摆件设计。原 `stls/turntable` 四个STL保留，新版在 `stls/turntable_compact`。源文件：`z_万物模型/053_紧凑省料旋转盒.scad`，依赖本机已有的BOSL2。

原模型是200mm圆盒、内齿圈顶盘、小齿轮和辅助销。新版沿用内齿圈驱动思路，重新生成尺寸和齿形，不能混用原齿轮。默认电机按用户“小步进电机”推定为28BYJ-48 **5V版**，并非已经识别了实物型号。

## 改了什么

| 项目 | 新版 |
|---|---|
| 外形 | 直径120 × 高35.6mm；占桌面积比200mm圆盒少64% |
| 外壳、底板、面板 | 名义厚度均1.6mm，面板背面8根加强筋 |
| 传动 | 模数1.25，80齿内齿圈 / 20齿小齿轮，4:1减速 |
| 支承 | 外缘3个滑台承重；8mm中心打印轴定位，直径间隙0.4mm |
| 电机安装 | 35mm耳孔距，机身直径28mm，输出轴偏心8mm |
| 控制仓 | 驱动板包络32×35×12mm；C3包络26×20×8mm，不含额外高插针和插头 |
| 出线 | 一个顶缘U形槽，默认适配约3.5–4mm线；内置螺丝压片 |
| 维护 | 顶盘可直接提起，底板与侧壁一体打印；侧壁无开关孔 |

这是样机，没有实物打印、耐久或200g负载测试。适合小型居中摆件，不把200g理解成任意偏心位置都可靠。顶盘没有防拔锁，搬运拿底座。

## 打印清单

V2取消底板与侧壁之间的接缝、四个连接螺丝座及四颗沉头螺丝。电机和控制板从上方装入，取下顶盘即可检修。

每件1个，STL已摆为打印方向：

- `base.stl`：底板、侧壁、电机柱、中心轴和三点支承一体。
- `platter.stl`：面朝热床，背面齿圈与加强筋向上。
- `pinion.stl`：小齿轮，5.2mm/3.2mm双D轴孔，径向紧定螺丝导孔。
- `cable_clamp.stl`：出线压片。

建议0.4喷嘴、0.2层高、4道墙，顶部/底部各4层，15%填充起步；大薄面和齿圈大多仍会成为实心。PLA先试装，轴孔和支承面去毛刺。按设计无需大面积支撑，径向2.6mm螺丝孔打印后清孔。小齿轮推荐单独先打印试配。顶盘和底板不要开大孔，保留连续面板有利于抗扭和防尘。

`print_layout`为两行排版，总范围250×250mm，256mm床面需检查切片机禁区；小机器按单件打印，最大单件120mm。不要对STL整体缩放。

## 螺丝与零件

| 零件 | 数量 / 说明 |
|---|---|
| 28BYJ-48 5V + ULN2003 | 各1；如不是此型号，请改安装参数后再打印 |
| ESP32-C3小开发板 | 1；板子和接头实际包络需符合控制仓 |
| M3×8盘头螺丝 | 2，固定电机安装耳 |
| M3×8无头紧定螺丝 | 1，顶住电机轴平面，外端要埋到齿根圆以内 |
| M2.5×6螺丝 | 2，固定出线压片，轻压线皮即可 |
| 细扎带 | 2–4，固定控制板；底板有架空筋和扎带槽 |
| Type-C线及5V供电 | 1路，建议5V/1A或以上电源 |

M3的2.6mm导孔先攻丝或低速试拧，避免撑裂薄柱。不同螺丝头和电机耳厚存在差异，首次试装检查有效咬合长度、螺丝是否顶底。

## 装配顺序

1. 不装电机，直接将顶盘套在一体底壳上。手转一整圈，顶盘应坐在三个小滑台上，中心轴孔不顶底；侧壁与盘底名义间隙0.6mm。
2. 去掉毛刺、确认三点等高。滑台可少量润滑，不能用润滑掩盖明显卡死。若粘贴减摩片，三个点必须等厚，并重新检查齿轮高度。
3. 取下顶盘，从上方装电机。电机机身向下，耳片坐在22mm高的柱上；输出轴朝上，偏心方向朝外圈。实物机身底端名义离底板1.4mm。
4. 小齿轮底面调到距离底板最底面25mm，齿轮顶面31mm，拧紧M3×8无头螺丝。螺丝必须沉入齿根以内，不能露头进入啮合区。轴孔过紧先修孔，过松用紧定螺丝固定。此孔没有打印花键。
5. 控制板放在左侧架空筋上，用扎带固定。把Type-C插头在盒内插好，线在压片处固定后，沿后壁内侧上行，从顶缘U槽出线；不用把插头穿过小孔。插头留在齿圈下方；上行线段沿后壁约Y=-56.2mm布置，避开半径约53.6mm的旋转齿圈，不能向内鼓起。三个支承点已避开出线方向。默认槽宽4.2mm，粗线需改参数。
6. 放顶盘时轻转至齿齿错开落座，先断电手转，再空载低速运行；依次加50g、100g、200g居中测试。建议先约0.5转/分钟，检查偏摆、齿噪、丢步和擦碰。

径向位置参数 `motor_adjust` ±0.5mm用于重打印底板时微调，不是实物长孔调节。齿轮总名义侧隙0.32mm；不能只改其中一个齿轮的模数/齿数。内啮合两齿轮同向转，小齿轮转4圈，顶盘转1圈。不同28BYJ减速箱实际减速比可能不是精确64，转速在现有程序中实测校准。

## 一根Type-C线供电

最少改动：Type-C插在C3开发板上，**仅在确认该板USB输入到5V/VBUS引脚的线路可承受电机和MCU总电流后**，从5V/VBUS分给ULN2003的电机电源；MCU、驱动共地，电机不接3.3V。

若开发板不适合转供电，在盒内加小型Type-C 5V取电板，输入5V分别供C3的5V输入和ULN2003；外面仍只有一根线。选择支持所用C-to-C/A-to-C线的成品取电板，不需要高压PD。分线板可布置在出线口左侧，实装确认插头及接线空间。这里设计的是线材出口，未假定某一款Type-C面板母座的安装孔。

不带额外外部开关；继续使用现有MCU控制程序，调至合适转速。没有把未经实机验证的固件混入此机械修改。

## 验证与体积口径

`mesh_report.json`记录四个STL的实体体积、尺寸、封闭性和连通体数量。`collision_report.json`记录一段齿距内8个角度的真实齿轮实体交集，以及顶盘与底板/外壳的交集；零交集不等同于实物公差、磨损、变形或承载测试。

实体体积对比见 `体积对比.json`：旧版统计Base + Top_plate + Motor_Gear，不计数量不明的辅助Pin；新版统计全部4件。此比较可说明几何减料，但不是切片后的耗材克数或打印时间。

电机尺寸参考：[28BYJ-48供应商图纸](https://www.electrokit.com/upload/product/41014/41014801/28byj48-5v.pdf)。齿形由本地BOSL2的 `ring_gear` / `spur_gear` 生成，压力角20°、零变位。
